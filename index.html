WGT Generator TV Edition

Оборачивает сайт в Tizen-приложение (.wgt) для Samsung TV. Автоопределение типа сайта и оптимальных настроек.

Навигация и экран
Авто: для кино/видео включает Smart Focus (стрелки пульта листают карточки), для остальных — Native.
Рекомендуется для YouTube, Netflix. Просто фокусирует iframe.
Стрелки двигают курсор, Enter = клик. Ограничен CORS.
Через прокси загружает HTML и внедряет навигацию стрелками. Самый надёжный.
Используется в режимах Smart Focus и Авто для кино-сайтов.
